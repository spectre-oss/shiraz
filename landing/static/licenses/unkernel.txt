unkernel — Linux on WebAssembly
Repository: https://github.com/pithings/unkernel
Website:    https://unkernel.dev/
Author:     Pooya Parsa <pooya@pi0.io>
Package:    unkernel (MIT AND GPL-2.0-only)

Shiraz's client-side in-browser runner uses unkernel to boot a real Linux 7.3
kernel compiled to WebAssembly with the kwemu aarch64 CPU emulator and JIT,
running Shiraz's unmodified aarch64 Linux runtime locally inside the visitor's
browser tab with zero backend compute.
