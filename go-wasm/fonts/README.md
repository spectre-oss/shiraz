# Manrope

The browser demo serves the unmodified Manrope variable TrueType font from
[Google Fonts](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/manrope).
Run `python3 go-wasm/bootstrap_font.py` from the repository root before serving
the demo. This downloads the pinned font into this static directory and checks
its SHA-256:
`3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.
The font is distributed under the SIL Open Font License 1.1 in `OFL.txt`.
