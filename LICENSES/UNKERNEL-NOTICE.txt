unkernel — Linux on WebAssembly
==================================

Shiraz's client-side browser APK runner (/run/) executes Shiraz's unmodified
aarch64 Linux runtime inside unkernel, an open-source project by Pooya Parsa (pi0).

Repository: https://github.com/pithings/unkernel
Website:    https://unkernel.dev/
npm:        https://www.npmjs.com/package/unkernel
Author:     Copyright (C) 2026 Pooya Parsa <pooya@pi0.io>

- unkernel's JavaScript/TypeScript SDK (js/, web/) is licensed under the MIT License.
- unkernel's kernel bundle (unkernel.wasm) contains the Linux 7.3 kernel with
  arch/wasm patches, the kwemu aarch64 CPU emulator/JIT, and Alpine BusyBox
  in its base initramfs, licensed under GPL-2.0-only / GPL-2.0-or-later.
- Shiraz's own code (GPL-3.0-only) runs strictly as unmodified aarch64 Linux
  userspace binaries communicating with unkernel over the standard Linux
