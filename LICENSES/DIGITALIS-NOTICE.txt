Digitalis / Berberis integration in Shiraz
========================================

Shiraz's optional ARM64 translation support uses Digitalis, based on the
Android Open Source Project's Berberis binary translator. Credit belongs to
utzcoz (https://github.com/utzcoz), the Digitalis contributors, and the
upstream Android Open Source Project authors. Digitalis identifies utzcoz
in its project attribution: https://digitalisx64.github.io/
The pinned translator revision also credits kuloPo (https://github.com/kuloPo)
as its author and utzcoz as its committer.
Their code retains its upstream licenses; Shiraz's GPL-3.0-only license does
not replace those notices.

Shiraz adaptations
------------------

scripts/digitalis/ contains Shiraz's local build integration and generated
source overlays. native/digitalis_bridge.cpp, digitalis_guest_tls.cpp,
digitalis_file_profile.cpp and digitalis_libm_proxy.cpp implement Shiraz's
experimental ART/JNI, guest TLS, file-profile and math adapters.
native/digitalis_nativewindow_proxy.cpp bridges the supported native-window
and hardware-buffer functions to Shiraz and is GPL-3.0-only.
native/digitalis_egl_proxy.cpp and native/digitalis_gles1_proxy.cpp adapt
registered EGL/GLES calls using Digitalis/Berberis ABI trampolines. These Shiraz
adapters and scripts/digitalis/build_nativewindow_proxy.py are GPL-3.0-only;
the upstream trampoline implementation retains its own license above.
native/guest_stack_environment.h provides Shiraz's bounded attached-stack
environment storage and is licensed GPL-3.0-only.
native/digitalis_libc_proxy.cpp retains its AOSP copyright and Apache-2.0
header; Shiraz's additions are GPL-3.0-only, as stated in that file.
These adaptations are not an unmodified upstream Digitalis distribution.
Source checkouts and generated binaries are kept outside tracked source files.

than using Refract's prebuilt host translator. Refract application code is not
part of this integration. The guest binaries retain their component licenses;
