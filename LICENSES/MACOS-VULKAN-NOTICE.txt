macOS Vulkan-over-Metal ICD (not vendored in the source tree)

On macOS arm64, `make macos-vulkan-deps` (`scripts/bootstrap_vulkan_darwin.py`)
downloads and checksum-verifies the pinned upstream KhronosGroup MoltenVK
release archive in the ignored `.deps/` directory and installs only the
macOS dynamic library and its license/provenance files in the ignored `.local/`
directory. Nothing is installed into the host system.
