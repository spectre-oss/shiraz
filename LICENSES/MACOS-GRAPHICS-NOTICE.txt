macOS text, path and image libraries (not vendored in the source tree)

On macOS, scripts/bootstrap_darwin_graphics.py downloads the unmodified upstream
release tarballs below, checks each against a pinned SHA-256, builds them as
static arm64 archives in the ignored .local directory, and links them into
build/macos/libshiraz-text.so (FreeType, HarfBuzz, fontconfig),
build/macos/libshiraz-path.so (cairo, pixman) and build/macos/libshiraz-image.so
(libwebp, libjpeg-turbo, and libpng from scripts/bootstrap_darwin.py). The
dylibs export only their JNI entry points. Each library's original license
files and a PROVENANCE file (URL, SHA-256, how the pin was checked, options)
are installed in .local/share/licenses/<name>/; any redistribution of these
dylibs must carry those files with them. zlib and expat are the macOS SDK's
system libraries, and ICU 78.3 is linked dynamically from .local/lib.
