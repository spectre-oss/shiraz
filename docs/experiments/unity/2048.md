# 2048 — Unity, older Mono release

- Upstream: [starsep/2048 v0.2.0](https://github.com/starsep/2048/releases/tag/v0.2.0).
- Artifact: `2048-Android-v0.2.0.apk`, unchanged; version code 4, min SDK 16.
- SHA-256: `ab66a4ea2586ad54408f4c4daa1a1fe271dd56487cbbdec04e35110a5e0bd69a`.
- Framework evidence: `libunity.so`, `libmono.so`, and `libmain.so`.
- Test: 2026-10-28 on the x86-64 Linux VM; source baseline `0b59ef2`.

## Result

**Unsupported ABI.** The APK contains only `armeabi-v7a` and `x86` native
libraries. Shiraz rejected launch with `APK has no native ABI candidate for this
host (x86_64)` before starting the app. Its optional ARM64 translator does not
supply a 32-bit ARM runtime.

No game frame or gameplay was observed. The APK was not modified, recompiled,
or relabeled as a 64-bit app. This release would require a supported 64-bit
upstream build or a separate 32-bit execution implementation. The
[Lucas Doggiehood experiment](LUCAS_DOGGIEHOOD.md) tests Unity with a 64-bit build.
